# Estado de desarrollo

Synchra se encuentra en fase de diseño y validación experimental. Todo el firmware publicado es código en proceso: se conserva para registrar la evolución técnica, no como una versión final lista para uso.

| Área | Situación |
| --- | --- |
| Firmware del ESC | En desarrollo: pruebas de BEMF, conmutación y arranque. |
| Firmware de radio | En desarrollo: prototipo RF24 disponible como etapa previa. |
| Radio LoRa 433 MHz | En desarrollo para próxima integración con EBYTE E32 y nueva antena. |
| Esquemáticos | Publicados en formato KiCad. |
| PCB | En proceso de diseño; no hay una revisión final de fabricación. |
| Evidencia de pruebas | Selección de mediciones de banco incluida en `media/experiments`. |

Los archivos de fabricación conservados en `archive/historical-gerbers` son exportaciones históricas y no deben tomarse como una liberación final de PCB.
