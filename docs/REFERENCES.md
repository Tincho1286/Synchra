# Referencias y atribuciones

FluxLink 433 publica el desarrollo propio, sus explicaciones tecnicas y la evidencia de avance. El informe privado presentado en la EETP no se publica. Las referencias externas se reconocen de manera explicita porque forman parte de la investigacion del proyecto.

## DukeDoks

Los modelos del vehiculo RC provienen de **DukeDoks**. Fueron utilizados como plataforma fisica de prueba para el ESC y el sistema de radio control. El vehiculo y sus STL no se presentan como desarrollo propio: se conservan localmente y se reconocen aqui como una referencia clave de la etapa de pruebas.

## Electronoobs y otros programas de referencia

Los programas presentes localmente en `[OPEN ESC´S]`, incluido material de Electronoobs, y otros sketches estudiados durante la investigacion fueron referencias para comprender estrategias de control de motores brushless sensorless. Esta procedencia se reconoce porque fue parte del proceso de aprendizaje; el firmware del ESC de FluxLink 433, incluido en `[PROGRAMAS]`, fue escrito integramente para este proyecto.

## LoRa de 433 MHz

La proxima actualizacion se apoya en recursos de la familia **EBYTE E32** para LoRa de 433 MHz, presentes localmente en `[ANTENA]`: manuales, ejemplos de comunicacion y recursos de encapsulado/PCB. El repositorio explica la arquitectura, los objetivos de validacion y las decisiones de integracion; el manual original se mantiene como material de consulta local.

## Informe EETP

El proyecto comenzo como un trabajo presentado en la Escuela de Educacion Tecnica Profesional. Ese informe es privado y no forma parte del repositorio. La documentacion publica fue reescrita y mantenida especificamente para FluxLink 433.
